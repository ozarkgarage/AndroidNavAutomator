Not intended for use on any device deemed critical. Use at your own risk.

App designed to turn an android device into a semi-dedicated navigation device. The goal was to have a dedicated phone for navigation that could be
left on the handlebars of a motorcycle with no accounts, subscriptions, or personal data in case of theft.

Power connected (ignition on): Screen on, force selected screen orientation, start selected navigation app
Power disconnected (ignition off): screen off

Requires permission to be run on top
Requires permission to unrestricted battery usage

Best used if developer options->screen on when power connected is enabled.
